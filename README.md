# Personal website for<br>Ramiro Barrantes-Reynolds

👋 Hello, and welcome to the repo for [my personal website](https://ramirobarrantes.github.io/).

This is a personal academic website built with [Quarto](https://quarto.org/), forked from [Silvia Canelón's excellent template](https://silviacanelon.com/) and personalized for a bioinformatics data scientist at the University of Vermont.

The website showcases research, publications, projects, and more in computational biology and bioinformatics.

This site was also an experiment: I used Claude Code for the technical heavy lifting while directing the work and filling in the personal content. Perhaps the best of both worlds.
